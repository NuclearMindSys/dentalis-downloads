# Dentalis — Official Downloads

Public download hub for Dentalis applications. صفحة التوزيع الرسمي العام لبرمجيات Dentalis.

## Dentalis GO 1.2.0 — Android

- From [Releases](https://github.com/NuclearMindSys/dentalis-downloads/releases): download **DentalisGO-1.2.0.apk**, open it, and allow "install unknown apps" once when prompted. Updates install over the old version and keep all data.

## Dentalis GO 1.2.0 — Windows

- From [Releases](https://github.com/NuclearMindSys/dentalis-downloads/releases): download **DentalisGo-Setup-1.2.0.exe** and run it. If Windows SmartScreen appears: "More info" / "مزيد من المعلومات" ثم "Run anyway". Upgrades install in place and keep all data.

> التحديثات تصلك داخل التطبيق تلقائياً؛ هذه الصفحة للتثبيت الأول والتنزيل اليدوي.
